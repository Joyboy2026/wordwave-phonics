# WORDWAVE 单词声波站

给五年级孩子的自然拼读学习站：42 个频道、840 个词，加上 WORD LAB 单词输出、48 音标发音室和拍照 OCR 读英文。

项目现在有两种运行方式：

- **GitHub Pages 静态演示（当前线上）**：打开即学，不需要登录，也不收费；学习进度只存在当前浏览器。账号、付费、管理后台的代码完整保留，但没有后端时不会启用。
- **Node 完整模式**：注册登录、会员付费（¥5 月卡 / ¥39 买断）、管理后台、学习时长统计，以及按成员隔离的云端学习记录。

线上静态页：<https://joyboy2026.github.io/wordwave-phonics/>。静态页右下角会显示“静态演示”提示；如需账号和收费，请按 [DEPLOY.md](DEPLOY.md) 用 `npm start` 部署 Node 版本。

> **说明：** GitHub Pages 只托管静态文件，无法运行 Node/SQLite API。静态模式不登录、不收款、不云同步；真实收款请部署 Node 模式。

## 功能总览

### 学习端

- 42 个自然拼读频道 / 840 个词，外研社五上、五下核心词 + 拓展词。
- 每 5 个词一批，3 道听音选择题；答对随机中文鼓励语音 + 彩带。
- WORD LAB：80 个重点词，认读 → 拼写 → 造句。
- 音标室：48 个国际音标，每个 5 个例词，支持慢速与掌握标记。
- 拍照读英文：本地 Tesseract OCR，整句朗读、逐词点读、翻译、收藏与历史。
- PWA：可安装到主屏幕，已缓存的页面 / 音频 / OCR 资源可离线使用。

### 账号与付费（仅 Node 完整模式）

> GitHub Pages 静态演示不启用本节功能；账号、支付和后台代码保留在仓库中。

- 用户名 + 密码注册、登录、退出、修改密码。
- 未登录只能看到登录页；已登录但未开通会员只能看到付费墙。
- 价格由服务端写死，前端不能改价：
  - **月卡 ¥5 / 30 天**，可叠加购买，从当前到期日往后加 30 天。
  - **买断 ¥39 / 永久**，买断后不再显示购买入口。
- 支持兑换码开通（适合线下收款后发码）。
- 每次进入学习页需要有效会员；管理员账号可直接进入，方便维护。

### 管理员后台 `/admin`

- 概览：总成员、有效付费、今日学习、累计学习、待确认订单、7 日新增；每日学习柱状图、模块分布、学习榜、最近订单。
- 用户管理：搜索、角色 / 状态 / 会员筛选、分页；新建（可自动生成初始密码）、编辑昵称 / 用户名 / 角色 / 状态、重置密码、停用 / 启用、删除。
- 会员管理：查看到期时间、开通月卡 / 买断、撤销会员、查看 30 天学习曲线与模块明细、学习记录条数。
- 订单：查看待确认 / 已支付 / 已取消；手动确认收款、取消订单。
- 兑换码：批量生成、复制、查看使用状态。
- 审计日志：管理员登录后的关键操作留痕（操作者、动作、对象、IP、时间）。

### 学习时长统计

- 学习页在前台每 45 秒发一次心跳（仅页面可见时）；服务端每次最多记 120 秒，避免伪造超长时长。
- 离线期间仍可学习，本地记录带写入时间戳；恢复联网后，比服务端更新的本地记录会回传，避免被旧快照覆盖。
- 按自然日汇总，默认时区 `Asia/Shanghai`；单日上限默认 720 分钟，可用 `STUDY_DAILY_CAP_MINUTES` 调整。
- 同时按模块统计：自然拼读、WORD LAB、音标、拍照识字、其他。
- 后台可按今日 / 近 7 天 / 近 30 天 / 累计查看每个成员，也可看全站汇总。

## 快速开始

### 静态预览 / GitHub Pages

直接打开线上地址即可。本地预览：

```bash
./start-server.sh          # http://127.0.0.1:8765/?static=1
```

静态模式不会请求 `/api`，学习记录使用浏览器本地存储，不需要 Node。

### Node 完整模式

要求 **Node.js >= 22.5**（使用内置 `node:sqlite`，不需要安装数据库，也没有 npm 依赖）。

```bash
cd .publish-wordwave
cp .env.example .env
# 编辑 .env，至少改 PORT 和 ADMIN_PASSWORD
npm run create-admin -- --username admin --password '换成你的强密码'
npm start
```

打开：

- 学习端：<http://127.0.0.1:8787/>
- 管理后台：<http://127.0.0.1:8787/admin>

首次启动时，如果数据库里还没有管理员，服务端也会按 `.env` 的 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 创建；没填密码则随机生成并写入 `data/initial-admin.txt`（权限 0600），请登录后立即改密码并删除该文件。

### 常用命令

```bash
npm start                 # 启动服务
npm run dev               # 带 --watch 的开发模式
npm test                  # Node 内置测试，13 项
npm run create-admin -- --username admin --password '...' --display-name '平台管理员'
npm run reset-password -- --username admin --password '...'
npm run backup            # 备份到 data/backups/wordwave-<时间>.db
```

`create-admin`、`reset-password`、`backup` 的实际入口是 `node server/cli.js <命令>`，可以加 `--help` 查看参数。

## 配置

复制 `.env.example` 为 `.env`，常用项：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `HOST` | `0.0.0.0` | 监听地址 |
| `PORT` | `8787` | 端口 |
| `DATA_DIR` | `data` | SQLite 数据库、备份、初始密码文件目录 |
| `APP_TIMEZONE` | `Asia/Shanghai` | 学习统计的自然日时区 |
| `STUDY_DAILY_CAP_MINUTES` | `720` | 每人每天最多计入的学习分钟数 |
| `PAYMENT_MODE` | `manual` | `manual` 人工确认；`mock` 本地测试秒开通 |
| `ADMIN_USERNAME` | `admin` | 首次启动无管理员时使用 |
| `ADMIN_PASSWORD` | 空 | 首次启动无管理员时使用；空则随机生成 |
| `SESSION_DAYS` | `30` | 登录有效期 |
| `COOKIE_SECURE` | `false` | HTTPS 部署必须设为 `true`；本机 HTTP 调试保持 `false` |
| `TRUST_PROXY` | `false` | 在 Nginx / Caddy 后面时设 `true`，用于取真实 IP |

**不要把 `.env` 或 `data/` 提交到 Git。** 两者都已在 `.gitignore` 中。

## 支付流程

### 生产：人工确认（`PAYMENT_MODE=manual`，默认）

1. 用户在付费墙选择月卡或买断，创建订单。
2. 用户按页面提示线下付款（微信 / 支付宝收款码由你自行放置，本项目不内置商户号）。
3. 管理员在 `/admin` → 订单确认里核对金额和用户，点“确认收款”。
4. 服务端在事务中把订单标记为已支付并开通会员；同一订单重复确认不会重复加时长。

这是 5 元 / 39 元小额度场景最稳妥的方式，不需要企业商户资质。若以后接入微信支付 / 支付宝，建议只改 `server/billing.js` 的 `createOrder` 和确认回调，并保留“服务端计算金额、幂等确认”的约束。

### 本地测试：模拟支付（`PAYMENT_MODE=mock`）

付费墙会显示“模拟支付并开通”，点一下立即到账。**上线前务必改回 `manual`**，否则任何人可以免费开通。

### 兑换码

管理员在“兑换码”页批量生成，格式 `WW-XXXX-XXXX-XXXX`。用户输入后立即开通对应套餐；一码一用，已使用会拒绝。适合学校 / 家长群统一收费后发码。

## 数据隔离与安全

- **一人一份学习数据。** 会话里的 `user_id` 由服务端决定，前端不能指定；`user_data` 以 `(user_id, key)` 为主键，任何读写都会校验会话。
- 客户端 localStorage 也按 `ww.u<用户ID>.` 前缀隔离，退出登录 / 切换账号会重新加载对应命名空间，避免上一个成员的进度出现在下一个成员面前。
- 密码使用 Node `crypto.scrypt`（N=16384, r=8, p=1）加盐哈希，数据库不保存明文。
- 会话 token 只通过 `HttpOnly` Cookie 下发，数据库只存 token 的 SHA-256；Cookie 默认 `SameSite=Lax`，HTTPS 下加 `Secure`。
- 所有写接口要求 `x-csrf-token`（登录 / 注册除外），并校验 `Origin`；管理接口额外校验 `role=admin`。
- 登录、注册、兑换码有按 IP / 用户的频率限制；SQL 全部参数化；管理操作写审计日志。
- 改密码、停用账号会立即撤销该用户全部会话；禁止管理员把自己降级、停用或删除，也禁止删除最后一个管理员。
- 备份文件包含密码哈希和学习数据，请按敏感文件保管。

### 必须知道的边界

1. **静态学习资源本身无法做到“不付费就绝对看不到”。** 本项目是 PWA，`index.html`、`data.js`、音频等必须能被浏览器下载；当前做法是服务端 API + 前端登录墙 + 会员校验。懂开发者工具的人仍可能绕过前端遮罩直接看静态内容，但**拿不到其他成员的数据，也不能通过 API 写数据**。如果业务上必须保护内容版权，需要改成服务端渲染 / 加密资源 + 授权解密，成本和离线能力都会受影响。
2. **离线宽限。** 已开通会员的设备断网后，可凭本地缓存的会员状态继续学习最多 72 小时；这是为了不破坏 PWA 离线体验。超过宽限或清除缓存后需要联网验证。
3. **没有找回密码邮件。** 当前是管理员重置密码模式，适合家庭 / 小班场景。要做短信 / 邮箱找回，需要接入相应服务商。
4. **不要用 `python3 -m http.server` 生产。** 它没有账号、没有 API，只能当纯静态预览。

## 学习流程：自然拼读

1. 首页选一个频道（或点“开始调频”从第一个未完成频道开始）；可用“课本词”只看含外研课本词的频道。
2. 逐词听发音，看音标、汉译、意思图和“拼一拼”拆解；支持 0.7× 慢速。例句右侧的“例句”按钮可朗读整句。
3. 每 5 个词看完后进入 3 道听音选择题；答错会显示正确答案并重播。
4. 一组 4 批都完成后播放中文鼓励语音，配合星星与 confetti 动画；进度同步到当前账号。
5. 每次答对会随机播放 6 种中文鼓励语音之一，并从选项位置喷出彩带礼花；答错仍重播正确单词。

## WORD LAB 学单词

独立的输出练习模块：认读 → 拼写 → 造句。

- 首批 80 个重点词，全部来自已有的 840 词：44 个外研五上/五下核心词 + 36 个拓展词。
- 每 5 个词一组，共 16 组；每个词三步完成后计入“已掌握”。
- 造句使用适当从句和简单时态；拼句前会显示中文意思，完成后显示“句型 / 时态”。
- 认读页的英文例句有独立的“例句”朗读按钮，使用本地音频。
- 频道页（前缀 / 后缀 / 字母组合）单词卡片的例句也有“例句”按钮，使用本地离线音频。
- 支持全部 / 课本 / 拓展筛选、随机 5 个、单字练习；进度同步到当前账号。

## 音标室 SOUND LAB

48 个国际音标，按中国课堂常用的“20 元音 + 28 辅音”组织。

- 元音：短元音 7、长元音 5、双元音 8；辅音：爆破音 6、摩擦音 9、破擦音 6、鼻音 3、舌侧音 1、半元音 3。
- 点开一张音标卡，可看发音口型提示、常见拼写和 5 个例词；点任意例词可切换并试听，支持 0.7× 慢速。
- 每个音标的首个例词音频在 `audio/ipa/<id>.mp3`，其余例词在 `audio/ipa/words/<slug>.mp3`；读的是例词（如 `/æ/` → cat），不单独朗读音标符号，避免机器合成把 IPA 读错。
- 支持“全部 / 元音 / 辅音”筛选、上一个 / 下一个切换、标记已掌握；进度同步到当前账号。
- 入口在首页 WORD LAB 卡片下方的蓝色“进入音标室”。

## 拍照读英文 PHOTO READER

拍英文书页、练习纸或路牌，在浏览器本地识别成一段可点、整句跟读高亮的英文，再逐句学习。

- 拍照 / 相册选图 → 本地 Tesseract OCR 识别，图片不上传；识别后直接显示为连续文本，每个单词都可点。原文仍可点“编辑原文”修改。
- 识别结果和逐句发音放在同一个阅读框里：每句话左侧有 ▶ 按钮，点一下朗读整句，再点 ■ 停止；支持 0.7 / 0.85 / 1 / 1.15 / 1.3 五档速度。设备有英文语音时优先使用；没有时使用百度在线整句语音（需联网，速度通过音频播放速度调整），在线语音失败才退回逐词发音。
- 朗读时整句话的背景高亮，不做句内单词逐词高亮；这样句子高亮和整句语音是对齐的，不会再出现单词语音和高亮错位。
- 正文下方会显示中文译文，由 MyMemory 在线翻译生成；只发送识别出的文字，不带照片。
- 点任意单词可听发音、看音标和中文释义；单词卡里可收藏 / 取消收藏，收藏的词在正文中变为珊瑚色，并收进页面底部的收藏夹。
- 每次识别会保存一条识别历史（最多 20 条，自动去重）；历史里可以重新打开原文、译文和逐句朗读，也可以删除单条或清空。历史同步到当前账号。
- OCR 常把大写字母 I 识别成竖线 `|`，识别结果会自动把它还原成 `I`。
- 本地词库来自 ECDICT 子集（57,841 词 + 32,412 个词形变化），课本词优先使用站内音标和释义。
- 发音顺序：站内离线录音 → 设备英文语音 → 在线发音；单词卡优先使用本地录音。
- 首次识别会加载本地 OCR 引擎和词库（约 14MB，之后由浏览器缓存）；拍照文字、译文、速度和收藏、识别历史都同步到当前账号。
- 入口在首页音标室卡片下方的蓝色“拍下来，读出声”卡片。

## 常见问题

**端口被占用？** 改 `.env` 的 `PORT`，或 `lsof -i :8787` 找到进程。不要直接杀未知进程。

**忘记管理员密码？** `npm run reset-password -- --username admin --password '新密码'`，会同时撤销该账号全部会话。

**用户被停用 / 会员过期？** 停用后现有会话立即失效；会员过期后进入付费墙，学习数据仍保留，续费后继续。

**数据存在哪？** 默认 `data/wordwave.db`（SQLite，WAL 模式）。备份用 `npm run backup`，恢复时停服务、替换数据库文件再启动。

**能部署到 GitHub Pages 吗？** 可以，当前线上就是静态演示：打开即学，但不能登录、收费或云同步。账号、付费和统计请用 Node 模式，见 [DEPLOY.md](DEPLOY.md)。

## 说明

- 发音为本地音频，不依赖浏览器 TTS；播放失败时会回退到 `speechSynthesis`。
- 含义图采用大号 emoji + 设计舞台，保证离线可用，不依赖外部图片。
- “课本词”筛选标记的是 44 个外研社（三起）五上/五下核心词，按拼读规则能自然分组的词收录；**不是完整教材词表**，后续可按单元继续补全。
- 登录后学习数据使用 `ww.u<用户ID>.` 前缀保存在 localStorage，并异步同步到服务端；缩放值 `wordwave.zoom.v1` 是设备级设置，不区分账号。
- 支持手势缩放：两指捏合可在 60%–120% 之间缩小 / 放大页面，双击在 100% 和 120% 之间切换；缩放后右侧会出现百分比小标签，点一下即可回到 100%。桌面端也可用 `Ctrl`/`Cmd` + `=`、`-`、`0`。
- 浏览位置记忆：从频道返回首页、从挑战返回频道、从 WORD LAB 返回词表、从音标室返回首页时，会回到离开前的滚动位置；再次进入同一个频道会回到上次浏览的单词。
- 支持键盘左右方向键切词、Esc 关闭弹层、`prefers-reduced-motion` 下关闭 confetti。
- 教材词表仅用于核对：五上 <https://yyld.51jiaoxi.com/wushang/wybsq_danci.html>；五下 <https://yyld.51jiaoxi.com/wuxia/wybsq_danci.html>。
