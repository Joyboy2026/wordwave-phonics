# WORDWAVE 单词声波站

给五年级孩子的手机端自然拼读练习页。42 个频道、840 个词，按前缀 / 后缀 / 字母组合分组，每组 20 词、每 5 词一批；含外研社五上/五下核心词和拓展词。另有 WORD LAB 单词输出练习、48 音标发音室（每个音标 5 个例词）和拍照 OCR 读英文。

## 打开

```bash
cd phonics-station
python3 -m http.server 8765 --bind 0.0.0.0
```

- 电脑本机：<http://127.0.0.1:8765/>
- 手机（同一 Wi-Fi）：`http://<目标机器局域网IP>:8765/`（IP 可能随网络变化，以 `hostname -I` 或 `ipconfig` 为准）
- 也可以直接运行 `./start-server.sh`，脚本会打印当前地址。

> 换机器/换网络请先看 [DEPLOY.md](DEPLOY.md)；`dsh-deploy.json` 是给其他 DSH 智能体读取的部署清单。

## 安装到手机（PWA）

已加入 `manifest.json`、`sw.js` 和全套图标，可以像 App 一样安装到主屏幕：

- **Android Chrome**：打开 HTTPS 地址 → 菜单 → “安装应用”/“添加到主屏幕”。
- **iPhone Safari**：打开 HTTPS 地址 → 分享 → “添加到主屏幕”。
- 首次打开需联网；加载过的页面、UI 音频会进入缓存，之后断网也能打开；单词音频、频道页例句音频、音标例词、WORD LAB 例句音频和拍照识字的引擎 / 词库在第一次使用后缓存。
- **安装只支持 HTTPS**（或本机 `localhost`）。用局域网 `http://IP:8765` 只能浏览，不能注册 Service Worker/安装。
- 安装后可全屏运行；进度仍保存在本机浏览器。

## 学习流程：自然拼读

1. 首页选一个频道（或点“开始调频”从第一个未完成频道开始）；可用“课本词”只看含外研课本词的频道。
2. 逐词听发音，看音标、汉译、意思图和“拼一拼”拆解；支持 0.7× 慢速。例句右侧的“例句”按钮可朗读整句。
3. 每 5 个词看完后进入 3 道听音选择题；答错会显示正确答案并重播。
4. 一组 4 批都完成后播放中文鼓励语音，配合星星与 confetti 动画；进度保存在浏览器本地。
5. 每次答对会随机播放 6 种中文鼓励语音之一，并从选项位置喷出彩带礼花；答错仍重播正确单词。

## WORD LAB 学单词

独立的输出练习模块：认读 → 拼写 → 造句。

- 首批 80 个重点词，全部来自已有的 840 词：44 个外研五上/五下核心词 + 36 个拓展词。
- 每 5 个词一组，共 16 组；每个词三步完成后计入“已掌握”。
- 造句使用适当从句和简单时态；拼句前会显示中文意思，完成后显示“句型 / 时态”。
- 认读页的英文例句有独立的“例句”朗读按钮，使用本地音频。
- 频道页（前缀 / 后缀 / 字母组合）单词卡片的例句也有“例句”按钮，使用本地离线音频。
- 支持全部 / 课本 / 拓展筛选、随机 5 个、单字练习；进度存在 `wordwave.wordlab.v1`。

## 音标室 SOUND LAB

48 个国际音标，按中国课堂常用的“20 元音 + 28 辅音”组织。

- 元音：短元音 7、长元音 5、双元音 8；辅音：爆破音 6、摩擦音 9、破擦音 6、鼻音 3、舌侧音 1、半元音 3。
- 点开一张音标卡，可看发音口型提示、常见拼写和 5 个例词；点任意例词可切换并试听，支持 0.7× 慢速。
- 每个音标的首个例词音频在 `audio/ipa/<id>.mp3`，其余例词在 `audio/ipa/words/<slug>.mp3`；读的是例词（如 `/æ/` → cat），不单独朗读音标符号，避免机器合成把 IPA 读错。
- 支持“全部 / 元音 / 辅音”筛选、上一个 / 下一个切换、标记已掌握；进度存在 `wordwave.ipa.v1`。
- 入口在首页 WORD LAB 卡片下方的蓝色“进入音标室”。

## 拍照读英文 PHOTO READER

拍英文书页、练习纸或路牌，在浏览器本地识别成一段可点、可跟读高亮的英文，再逐词学习。

- 拍照 / 相册选图 → 本地 Tesseract OCR 识别，图片不上传；识别后直接显示为连续文本，每个单词都可点。原文字仍可点“编辑原文”修改。
- 识别完成后可自动朗读，支持 0.7 / 0.85 / 1 / 1.15 / 1.3 五档速度；朗读时当前单词逐词高亮跟读，也可手动点“朗读全文”。
- 点任意单词可听发音、看音标和中文释义；单词卡里可收藏 / 取消收藏，收藏的词在正文中变为珊瑚色，并收进页面底部的收藏夹。
- 本地词库来自 ECDICT 子集（57,841 词 + 32,412 个词形变化），课本词优先使用站内音标和释义。
- 发音顺序：站内离线录音 → 设备英文语音 → 在线发音；设备没有英文语音时，全文朗读会逐词播放本地 / 在线发音。
- 首次识别会加载本地 OCR 引擎和词库（约 14MB，之后由浏览器缓存）；拍照文字、速度和收藏保存在 `wordwave.ocr.v1`。
- 入口在首页音标室卡片下方的蓝色“拍下来，读出声”卡片。

## 文件

- `index.html` — 页面、样式、交互
- `data.js` — 42 组 / 840 词数据（其中 44 个外研核心词）
- `lab.js` — WORD LAB 80 个重点词、例句与语法提示
- `ipa.js` — 48 个音标、每个 5 个例词、口型提示与常见拼写
- `ocr-dict.json` — 拍照识字的本地英汉词库（ECDICT 子集，57,841 词）
- `ocr-forms.json` — 词形变化 → 原形索引（32,412 条）
- `vendor/tesseract/` — 本地 OCR 引擎、英文语言包与许可证（约 9.6MB）
- `audio/words/` — 840 个单词发音（en-GB）
- `audio/ui/` — 6 种随机答对提示、每批鼓励、频道完成鼓励、全对鼓励
- `audio/lab/sentences/` — 80 个 WORD LAB 例句朗读（en-GB）
- `audio/ipa/` — 48 个音标首例词朗读（en-GB，按音标 id 命名）
- `audio/ipa/words/` — 163 个补充例词朗读（en-GB，按单词命名）
- `audio/sentences/` — 840 个频道页例句朗读（en-GB，按单词命名）
- `fonts/fredoka-latin.woff2` — 本地字体
- `favicon.svg` — 站点图标
- `manifest.json` — PWA 清单（名称、图标、独立窗口）
- `sw.js` — Service Worker，离线缓存
- `icons/` — PWA / 主屏幕图标
- `qr-lan.png` — 本机生成的可选二维码；换机后 IP 会变，需要重新生成或直接发 URL（发布包未包含）
- `start-server.sh` — 本地静态服务启动脚本
- `DEPLOY.md` — 移植、手机访问、DSH 智能体部署说明
- `dsh-deploy.json` — 机器可读的部署清单

## 说明

- 发音为本地音频，不依赖浏览器 TTS；播放失败时会回退到 `speechSynthesis`。
- 含义图采用大号 emoji + 设计舞台，保证离线可用，不依赖外部图片。
- “课本词”筛选标记的是 44 个外研社（三起）五上/五下核心词，按拼读规则能自然分组的词收录；**不是完整教材词表**，后续可按单元继续补全。
- 拼读进度保存在 `localStorage` 的 `wordwave.progress.v1`；WORD LAB 进度保存在 `wordwave.wordlab.v1`；音标掌握进度保存在 `wordwave.ipa.v1`；拍照识字的文字、速度和收藏夹保存在 `wordwave.ocr.v1`。页面底部重置会清空拼读、WORD LAB、音标和拍照收藏夹（识别文字保留，需点两次确认）。
- 支持手势缩放：两指捏合可在 60%–120% 之间缩小 / 放大页面，双击在 100% 和 120% 之间切换；缩放后右侧会出现百分比小标签，点一下即可回到 100%。桌面端也可用 `Ctrl`/`Cmd` + `=`、`-`、`0`。缩放值保存在 `localStorage` 的 `wordwave.zoom.v1`。
- 浏览位置记忆：从频道返回首页、从挑战返回频道、从 WORD LAB 返回词表、从音标室返回首页时，会回到离开前的滚动位置；再次进入同一个频道会回到上次浏览的单词。记录保存在 `localStorage` 的 `wordwave.browse.v1`。
- 支持键盘左右方向键切词、Esc 关闭弹层、`prefers-reduced-motion` 下关闭 confetti。
- 教材词表仅用于核对：五上 <https://yyld.51jiaoxi.com/wushang/wybsq_danci.html>；五下 <https://yyld.51jiaoxi.com/wuxia/wybsq_danci.html>。
